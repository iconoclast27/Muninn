## Key conventions to preserve

- **Fixture-first:** any bug fix or new behavior needs a failing fixture before the code change.
- **A release is not THE release:** `0.2.0-test.8` is an intermediate testing artifact; flag remaining owed items in tag/release notes.
- **Dark-safe API:** frozen API returns `null` + reason, never throws.
- **API door terminology:** store interface methods are "API doors" per spec v3.
- **Include doc changes in the same commit** when they contextualize code changes.
- **Live docs in `docs/`; dead docs in `docs/ARCHIVE/`.**
- **Wait for plugin readiness logs** before running console diagnostics in Obsidian (`[Muninn] loaded cache:` or `[Muninn] no existing cache to load:`).
- **Distinguish plugin API from host features** in manual-test instructions.
